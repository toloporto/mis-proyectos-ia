# Enciclopedia Técnica: Auditor de Seguridad
Este proyecto sirve como referencia para:
1. **Rutas**: Uso de `sys.path` para conectar `src/` con `herramientas/`.
2. **Skills**: Estructura de una `@tool` para lectura de archivos.
3. **Agentes**: Configuración de Llama 3.1 con `max_iter` para evitar bucles.
4. **Documentación**: Script automático para generar READMEs.

**Uso rápido:**
- Meter log en `datos/`.
- Actualizar ruta en `src/main.py`.
- Ejecutar: `python3 src/main.py`.
