🏥 Sistema Multiagente Médico

IA multiagente para triage, diagnóstico y tratamiento

📦 GitHub ⚡ Actions

🤖 3 Agentes IA en cadena

  • 🔴 TRIAGE - Clasifica nivel de urgencia
  • 🩺 DIAGNÓSTICO - Identifica condiciones
  • 💊 TRATAMIENTO - Recomienda acciones

🚀 Instalación rápida

git clone https://github.com/toloporto/mis-proyectos-ia.git
cd mis-proyectos-ia
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
ollama pull phi3:latest
python src/api/api.py

Luego abre: http://localhost:8000/web

📊 Ejemplo de API

curl -X POST http://localhost:8000/consultar \\
  -H "Content-Type: application/json" \\
  -d '{"sintomas": "dolor de cabeza"}'
