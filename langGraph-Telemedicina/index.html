📋 Descripción del Proyecto

Sistema inteligente que utiliza LangGraph para orquestar 3 agentes IA especializados que trabajan en cadena:

  • 1️⃣ TRIAGE → Clasifica la urgencia
  • 2️⃣ DIAGNÓSTICO → Identifica la condición
  • 3️⃣ TRATAMIENTO → Recomienda acciones

Completamente gratuito y local usando Ollama. Sin costes de API, sin internet requerida.

🚀 Características Principales

  • ✅ 3 agentes IA trabajando en cadena con LangGraph
  • ✅ API REST profesional con FastAPI
  • ✅ Modelos de IA locales con Ollama (phi3, llama3, tinyllama)
  • ✅ Caché inteligente para respuestas instantáneas
  • ✅ Base de datos SQLite para persistencia
  • ✅ Rate limiting y seguridad
  • ✅ Interfaz web moderna y responsive
  • ✅ Logging profesional con trazabilidad
  • ✅ CI/CD con GitHub Actions
  • ✅ Despliegue con Docker

📦 Instalación Rápida

git clone https://github.com/toloporto/mis-proyectos-ia.git
cd mis-proyectos-ia
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
ollama pull phi3:latest
python src/api/api.py

Luego abre tu navegador en: http://localhost:8000/web

🔧 API Endpoints

  • GET / - Información de la API
  • POST /consultar - Realizar consulta médica
  • GET /estadisticas - Estadísticas del sistema
  • GET /consultas - Listar consultas realizadas
  • GET /pacientes - Listar pacientes registrados
  • GET /web - Interfaz web interactiva
  • GET /docs - Documentación Swagger
  • GET /health - Health check del sistema

📊 Ejemplo de Uso con cURL

curl -X POST http://localhost:8000/consultar \\
  -H "Content-Type: application/json" \\
  -d '{"sintomas": "dolor de cabeza", "edad": 30}'

Respuesta esperada:

{
  "triage": "MODERADO - Evaluación médica recomendada",
  "diagnostico": "Posible migraña o cefalea tensional",
  "tratamiento": "Reposo e hidratación. Consultar si persiste",
  "nivel_urgencia": "MODERADO"
}
