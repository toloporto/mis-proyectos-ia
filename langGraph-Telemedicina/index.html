🏥 Sistema Multiagente Médico

IA multiagente para triage, diagnóstico y tratamiento médico

Python 3.12 FastAPI LangGraph
📦 GitHub ⚡ Actions
🔴

Agente TRIAGE

Clasifica el nivel de urgencia: LEVE, MODERADO, GRAVE o EMERGENCIA

🩺

Agente DIAGNÓSTICO

Identifica posibles condiciones médicas basadas en los síntomas

💊

Agente TRATAMIENTO

Recomienda acciones médicas y señales de alarma

🚀 Instalación Rápida

git clone https://github.com/toloporto/mis-proyectos-ia.git
cd mis-proyectos-ia
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
ollama pull phi3:latest
python src/api/api.py

Luego abre: http://localhost:8000/web

📊 Ejemplo de uso con API

curl -X POST http://localhost:8000/consultar \\
  -H "Content-Type: application/json" \\
  -d '{"sintomas": "dolor de cabeza", "edad": 30}'

Respuesta esperada:

{
  "triage": "MODERADO - Evaluación médica recomendada",
  "diagnostico": "Posible migraña o cefalea tensional",
  "tratamiento": "Reposo e hidratación. Consultar si persiste"
}

🔧 Endpoints de la API

  • GET / - Información de la API
  • POST /consultar - Realizar consulta médica
  • GET /estadisticas - Estadísticas del sistema
  • GET /consultas - Listar consultas
  • GET /pacientes - Listar pacientes
  • GET /web - Interfaz web interactiva
  • GET /docs - Documentación Swagger
  • GET /health - Health check
